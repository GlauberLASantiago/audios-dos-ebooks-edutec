      Como acrescentar novos áudios à biblioteca

      Coloque os arquivos na pasta audios do repositório no GitHub. Após salvar, aguarde a publicação automática e atualize esta página. Não é necessário editar o player.

      Arquivos com mais de 25 MB devem ser enviados pelo GitHub Desktop ou por Git. O limite por arquivo no repositório é 100 MB. As instruções estão no guia do projeto.
